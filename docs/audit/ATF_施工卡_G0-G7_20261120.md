## 新会话统筹协议

### 分派顺序（不可跳）

```
1. 先做 G0（串行，1-2 天）
2. G0 完成后，同时派 G1 + G2 + G4（三组并行）
3. G2 完成后派 G3
4. G1+G3 完成后派 G5
5. G5 完成后派 G6
6. G6 完成后派 G7
```

### 每次派 agent 前必做

1. **声明文件范围**：明确该 agent 能改哪些目录，其它一律禁止
2. **确认无重叠**：与正在运行的 agent 对比文件范围
3. **给出验收命令**：让 agent 自己先跑一遍再交

### 每组完成后必做

1. `npm run audit:all`（三层）
2. typecheck
3. 相关测试
4. 独立提交（不合并多组）

### 风险控制

| 风险 | 控制 |
|---|---|
| 并行 agent 改同一文件 | 派发前声明范围 + git 提交前检查 `git status` |
| worktree vendor 是空目录 | 跑审计器前软链主仓，**提交前必须删软链** |
| 陈旧 `.js` 残留 | 改 packages 前先清 `find -name "*.js" -newer package.json` |
| dev 不可用 | 全程在 worktree，G7 才切 |
